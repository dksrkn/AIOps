# Energy AIOps API

업로드된 CSV 파일로 전력소비량 시계열 예측을 수행하고, 실제값 기반 RMSE를 통해 성능을 모니터링하며, 임계치 초과 시 자동 재학습 및 모델 교체까지 수행하는 AIOps 시스템입니다.

---

## 1. 프로젝트 개요

이 프로젝트는 단순 예측 모델이 아니라  
운영 환경에서 성능 저하를 감지하고 자동으로 모델을 개선하는 구조(AIOps)를 구현하는 것을 목표로 합니다.

---

## 2. 데이터 정의

### 사용 데이터

- train.csv: 시간 단위 전력 소비량 데이터
- test.csv: 예측 대상 데이터
- building_info.csv: 건물 정적 정보

### 문제 정의

건물별 시간 단위 전력 소비량(kWh)을 예측하는 시계열 회귀 문제

---

## 3. 데이터 분석 (EDA)

EDA를 통해 다음과 같은 특징을 확인했습니다.

### 1) 강한 시간 패턴
- 시간대별 소비량 변화 존재
- 주중/주말 패턴 차이 존재

### 2) 외부 요인의 영향
- 기온, 습도 등 날씨 변수와 소비량 상관관계 존재

### 3) 자기상관성
- 이전 시간 소비량이 현재 소비량에 큰 영향

---

## 4. 전처리 과정

### 1) 데이터 병합

train + building_info를 건물번호 기준으로 병합

→ 건물 특성을 모델 입력으로 사용하기 위함

---

### 2) 시간 처리

- datetime 변환
- 정렬 (건물번호 + 시간 기준)

→ 시계열 순서 보장

---

### 3) 결측치 처리

- 수치형: median 또는 0
- 시계열 구조 유지 위해 drop하지 않음

---

### 4) 스케일링

- StandardScaler 적용
- 입력 feature와 target 분리 스케일링

→ LSTM 학습 안정성 확보

---

## 5. Feature Engineering

### 1) 시간 기반 feature

- hour
- dayofweek
- month
- is_weekend

→ 전력 소비의 주기성 반영

---

### 2) 주기성 인코딩

- sin/cos 변환

→ 시간의 순환 구조 반영

---

### 3) 건물 feature

- 건물유형 (one-hot)
- 연면적, 냉방면적
- 태양광 / ESS 여부

→ 건물별 소비 패턴 차이 반영

---

### 4) lag feature

- lag1_kwh

→ 전력 소비의 자기상관 반영

---

## 6. 모델 구조

- LSTM 기반 시계열 모델
- 입력: sequence 형태 (과거 데이터)
- 출력: 다음 시점 소비량

---

## 7. 학습 방법

- 건물별 마지막 7일을 validation으로 사용
- optimizer: Adam
- loss: MSELoss
- sequence 기반 학습

---

## 8. 평가 방법

### RMSE 사용

RMSE = sqrt(mean((y_true - y_pred)^2))

→ 큰 오차에 민감하여 실제 운영 환경에 적합

---

### 추가 분석

- 전체 RMSE
- 건물별 RMSE

→ 성능이 낮은 구간 분석 가능

---

## 9. AIOps 구조

### 전체 흐름

CSV 업로드
→ 전처리
→ 예측
→ RMSE 계산
→ 임계치 초과 여부 판단
    → 초과: 재학습
    → 개선 시 모델 교체

---

### 재학습 조건

if rmse > 250

---

### 모델 교체 조건

if new_rmse < old_rmse

---
